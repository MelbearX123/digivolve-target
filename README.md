# I love Digimon

As a huge digimon fan, I immediately blew 100 dollars on the latest big digimon game, "Digimon: Time Stranger" when the pre-order released. I was too young to buy Digimon Cyber Sleuth when it came out so I was ecstatic when Time Stranger was announced. I'm a bit of a completionist so needless to say, I had to try get every single digimon.

Unlike pokemon, digimon have digivolution branches rather than just lines. With a few digivolutions/de-digivolutions, you can easily go from a a furry sea lion to an evil devil lady.

Current Features:
- Step by step instructions from one digimon to another via BFS
